# Хочу! 💖

AI-помощник для шопинга в стиле TikTok.

## 🎯 Что умеет приложение:

- ✨ **Умный поиск** — понимает запросы на естественном языке ("белая футболка хлопок дешевле 1000")
- 🛍️ **Сравнение маркетплейсов** — Wildberries и Ozon в одном месте
- 💖 **Коллекции "Хочушки"** — сохраняйте товары в красивые коллекции
- 🎨 **TikTok-стиль** — яркие градиенты, крупные элементы, адаптивность

## 🚀 Технологии:

- Flutter 3.x
- Dart
- Deep Links для Wildberries и Ozon
- Локальное хранение данных (SharedPreferences)
